# Conversor de Documentos

Este é um projeto em Java desenvolvido para realizar a conversão automatizada de diferentes formatos de arquivos e documentos.

## 🚀 Tecnologias Utilizadas
* Java
* Maven

## 💻 Como rodar o projeto
1. Clone o repositório:
   ```bash
   git clone git@github.com:akinoryyyyy/Conversor_Documentos.git
   ```
2. Abra o projeto na sua IDE favorita.
3. Execute a classe `Main.java`.
